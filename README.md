# MOJE FINANCE 💜

Osobní webová aplikace na evidenci příjmů a výdajů. Data se ukládají jen do localStorage v prohlížeči, nikoliv do GitHubu. Zálohování přes JSON export/import.

## GitHub Pages
Settings → Pages → Deploy from a branch → main → /(root) → Save.

Na iPhonu otevři zveřejněnou adresu v Safari a použij Sdílet → Přidat na plochu.
